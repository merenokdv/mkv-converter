# MP4 → MKV Converter

Локальный веб-конвертер: меняет контейнер MP4 на MKV **без перекодирования** (remux через ffmpeg). Качество не теряется — видео и звук копируются как есть.

## Требования

- Python 3.10+
- [ffmpeg](https://ffmpeg.org/) (`sudo apt install ffmpeg`)

## Запуск

```bash
./start.sh
```

Откроется браузер: http://127.0.0.1:8765/

Без браузера:

```bash
./start.sh --no-browser
```

## Возможности

- Выбор отдельных файлов или целой папки
- Очередь с прогрессом в реальном времени
- Сохранение MKV рядом с исходником или в другую папку
- Опционально: перезапись и удаление исходного MP4 после успеха
- Пометка повреждённых / недокачанных файлов (нет `moov`)

## Остановка

В терминале: `Ctrl+C`
